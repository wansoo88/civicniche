# prevalidation (옵션 1 · §13)

빌드 **착수 전** 가장 약한 두 가정을 소규모·저비용으로 먼저 깨거나 확정합니다.
둘 다 GO여야 본 빌드(`packages/data-pipeline`, `packages/site`)로 넘어갑니다.

## 13-A. 데이터 직판 수요 (`13a-data-demand/`)

- **가설:** 정의된 페르소나가 정제 데이터를 $29~99에 산다.
- **방법:** `index.html`(의향 수집 랜딩)을 띄우고 → 데이터 마켓·개발자/연구 커뮤니티·콜드아웃리치로 **수요처에 직접 가져간다**(사이트 트래픽에 의존하지 않음, §7-b 발견성 모순 해소).
- **실행:** `index.html`을 브라우저로 열기. 실제 수집은 `FORM_ENDPOINT`에 Formspree/Tally/Google Form URL을 넣으면 됨. 비우면 `localStorage` 데모.
- **통과 기준[임의, 사전 고정]:** 샘플요청 5+ 또는 사전결제의향 1+. → 미달이면 **G9: 직판 비가동**(모델이 'SEO 단일채널' 고위험 베팅으로 환원, §13-결정).

## 13-B. LLM 반복비 (`13b-llm-cost/`)

- **가설:** 반복 정제비가 월 $5~25에 수렴(§3.2).
- **실행:** `node measure.mjs` (키 없으면 mock 추정, 있으면 실청구).
- **보정:** `measure.mjs`의 `ASSUMPTIONS`(레코드 수·월변경률·경계율)를 실제 니치 규모로 교체.
- **통과 기준:** 추정 반복비가 `LLM_MONTHLY_BUDGET_USD`(기본 $30) 이내. 초과면 규칙 통과율↑·소스 단순화·니치 교체.

## 결정 규칙 (§13-결정)

| 13-A | 13-B | 결정 |
|---|---|---|
| GO | GO | ✅ `packages/data-pipeline` 착수 |
| NO | GO | 직판 안전판 제거 → 고위험 베팅 명시 수용 or 니치 재선정 |
| — | NO | 소스·니치 조정 후 재측정, 해소 불가면 보류 |
| NO | NO | 본 모델 착수 보류, 후보 재탐색 |
